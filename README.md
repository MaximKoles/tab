# Гонорар — учёт доходов фрилансера

Веб-приложение для тех, кто ведёт учёт в таблице и хочет видеть больше: откуда
приходят деньги, как растёт доход и кто из клиентов ещё не доплатил. Полностью
работает в браузере, данные хранятся только на устройстве пользователя.

**Демо:** после публикации — `https://maximkoles.github.io/tab/`

## Главные сценарии

- **Переезд из таблицы за минуту.** При первом запуске приложение предлагает
  загрузить CSV-выгрузку таблицы (Google Sheets → Файл → Скачать → CSV).
  Колонки «Дата, Сумма, Тип, Описание, Имя, Контакты, Источник, Коммент»
  распознаются сами, пары «предоплата/остаток» склеиваются в сделки,
  категории из таблицы появляются в приложении.
- **Откуда деньги.** В аналитике первым блоком — рейтинги источников и услуг
  с долями от дохода за выбранный год.
- **Прогресс.** На главном экране — прибыль месяца и тренд против предыдущего
  месяца, заполненные месяцы видны на полосе навигации.
- **Быстрая запись.** Одна кнопка «Повторить доход» (сумма, услуга, клиент —
  как в прошлый раз) и кнопка «Записать остаток» по открытым сделкам.

## Экраны

- **Учёт** — месяц с итогами, открытые доплаты, операции по дням
- **Клиенты** — сводка, фильтры «с долгом» и «молчат 45+ дней», карточка
  клиента с историей платежей по месяцам
- **Аналитика** — динамика года, «Откуда деньги», услуги по месяцам,
  доходы/расходы, структура расходов
- **Ещё** — поиск по всем данным, текстовый отчёт за месяц, импорт/экспорт
  CSV, бэкап JSON, тема, категории

## Pro (разовая оплата, без подписки)

Бесплатная версия: до 30 операций и 10 клиентов. Pro снимает лимиты и
добавляет цель месяца, сравнение лет, облачную синхронизацию (Supabase) и
экспорт CSV. Ключи выдаются скриптом `scripts/gen-key.mjs` (см. `DEPLOY.md`).

## Разработка

```bash
npm install
npm run dev          # http://localhost:3000
npm run build        # прод-сборка (standalone)
npm run build:pages  # статика для GitHub Pages в out/ (basePath /tab)
```

Деплой на Pages автоматический: push в `main` → GitHub Actions
(`.github/workflows/deploy.yml`). Подробности о синхронизации, выдаче ключей
и Telegram Mini App — в [DEPLOY.md](DEPLOY.md).
